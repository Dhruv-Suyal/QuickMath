# QuickMath (React + Vite)

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build in /dist
```

- Next question appears automatically when your typed answer is correct.
- Wrong answers shake and clear; **Tab** or the Skip button skips a question.
- Stats: avg speed per operation (bar chart) and time per question (line chart) via Recharts.
